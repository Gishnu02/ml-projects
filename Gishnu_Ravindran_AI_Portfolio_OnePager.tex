\textbf{Core Architecture:} Hybrid AI combining \textbf{Google OR-Tools (CVRPTW)} with an \textbf{XGBoost Regressor} \hfill \textbf{Jan 2026} \\
\textit{\small Tech Stack: Python, Google OR-Tools, XGBoost, FastAPI, Pandas, NumPy, Leaflet} \hfill \href{https://github.com/Gishnu02/ml-projects}{\color{NavyBlue}\small github.com/Gishnu02/ml-projects}

\begin{itemize}
    \resumeItem{\textbf{The Problem:} Classical routing algorithms optimize strictly for geometric shortest distance, failing when sudden rainstorms and peak rush-hour gridlock create compounding delays that breach customer delivery SLAs.}
    \resumeItem{\textbf{Machine Learning Pipeline:} Trained an \textbf{XGBoost Regressor} on 25,000 multi-factor delivery records (weather, precipitation, traffic multipliers 1.0x--2.8x, road incident proximity), achieving an \mbox{$\mathbf{R^2}$ \textbf{score of 0.9814}} and an average prediction error (MAE) of only \textbf{1.13 minutes}.}
    \resumeItem{\textbf{Operations Research Integration:} Fed the ML-predicted transit duration matrix directly into Google OR-Tools constraint solvers. The solver preemptively diverts commercial fleets around bottlenecks, increasing on-time SLA compliance by \textbf{+12.4\%}.}
    \resumeItem{\textbf{Live System Deployment:} Built an asynchronous \textbf{FastAPI} backend enabling continuous sub-100ms re-optimization triggered by interactive map order drops, dynamic road closures, and live weather updates.}
\end{itemize}
